## The word

**toilet**

One word for the whole internet. The phone on the toilet is the one
internet ritual everyone shares — the place where the whole world
scrolls, argues, laughs and doomscrolls at once. Funny on its own,
true of the internet as a whole rather than any one app, surprising
next to the obvious picks, and it lands in a single beat.

## How it works

`main.py` writes exactly that one word — and nothing else — to
`/output/entry.txt`:

```sh
python3 main.py
```

The program validates the word first: exactly one word, 1–30
characters, no whitespace, no trailing newline.
